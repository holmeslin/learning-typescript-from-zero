# 類別

前面幾章的資料都是用大括號直接寫出來的物件，搭配 `type` 描述它的形狀。這種寫法很好用，但有些東西光有資料不夠：一個銀行帳戶，除了「戶名」和「餘額」，還要有「存款」、「提款」這些動作，而且餘額不應該讓外面的人隨便改。

**類別**（class）就是把「資料」和「操作這些資料的函式」包在一起的工具。用類別可以一次產生很多個長得一樣的物件，也可以決定哪些屬性外面看得到、哪些只有自己能動。

類別是 JavaScript 本身就有的語法，TypeScript 在上面多加了幾樣東西。這一章兩者一起教，不需要你先會 JavaScript 的類別：

- 類別的屬性、建構子和方法
- 控制誰能存取：`public`、`private`、`protected`，以及 JavaScript 的 `#` 私有欄位
- 不能修改的 `readonly` 屬性
- 繼承：用 `extends` 擴充別的類別，用 `override` 改寫方法
- 用 `interface` 和 `implements` 規定類別要有哪些東西
- 抽象類別和 `static` 成員
- 類別本身也是一種型別

真實專案裡，很多程式碼用物件加函式就夠了，不一定要用類別。但你一定會在函式庫和別人的程式碼裡看到類別，`Date`、`Map`、`Error` 也都是類別。這一章讓你看得懂、也寫得出來。

這一章會用到第 3 章的物件型別、第 4 章的函式型別，以及第 5 章的 `instanceof` 縮小。範例一樣在 `ts-practice` 資料夾裡練習。
