# 基本型別

第 1 章只用到 `string`、`number`、`boolean` 三種型別。這一章把 JavaScript 裡最基本的幾種值，都配上對應的型別：

- 字串、數字、布林值，以及它們常見的陷阱。
- 陣列和元組：一串同樣的東西，或是固定位置、固定型別的一組東西。
- `null` 和 `undefined`：「沒有值」在 TypeScript 裡要怎麼說清楚。
- `any` 和 `unknown`：兩種「什麼都可以」的型別，一個危險、一個安全。
- 型別別名：幫型別取名字，讓程式碼更好讀。

這一章的範例都在 `ts-practice` 資料夾裡執行，每一集建立新的 `.ts` 檔。故意寫錯的檔案，看完記得改對或刪掉。
