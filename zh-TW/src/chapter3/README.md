# 物件型別

JavaScript 的程式，大部分的資料都是物件：一個使用者、一筆訂單、一份設定。第 2 章教的 `string`、`number` 只能描述一個值，這一章要學怎麼描述「一個物件長什麼樣子」：有哪些屬性、每個屬性是什麼型別、哪些可以不填、哪些不能改。

這一章會學到：

- 物件型別的寫法，以及用型別別名替它取名字
- 可選屬性和 `readonly`
- `type` 與 `interface` 兩種寫法，以及怎麼組合型別
- 巢狀物件、物件陣列，和「屬性名稱不固定」的物件
- TypeScript 比對物件的兩個規則：多餘屬性檢查和結構型別

學完這一章，你就能替真實專案裡大部分的資料寫出型別了。範例一樣在 `ts-practice` 資料夾裡練習。
