# 函式的型別

第 1 章學過最基本的寫法：參數標型別，回傳型別寫在小括號後面。但真實的函式沒那麼單純。有的參數可以不傳，有的參數可以傳任意多個，有的參數是一整個物件，還有的參數本身就是另一個函式。

這一章把函式從頭到尾看一遍：

- 呼叫時參數的數量對不對、回傳的東西對不對，TypeScript 怎麼檢查。
- 回傳型別什麼時候該寫、什麼時候交給推論，以及什麼都不回傳的 `void`。
- 可選參數、預設參數、其餘參數。
- 用物件當參數，搭配解構，以及一個很常見的寫法陷阱。
- 把「函式長什麼樣子」寫成型別，用來描述 callback。
- 函式多載：同一個函式，傳不同的東西，回傳不同的型別。

這一章會用到第 2 章的陣列型別和型別別名，以及第 3 章的物件型別。範例一樣在 `ts-practice` 資料夾裡練習。
