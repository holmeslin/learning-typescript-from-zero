# 非同步與外部資料

到目前為止，範例裡的資料都是你自己在程式碼裡寫好的，TypeScript 看得到每一個值，所以能檢查每一個型別。

真實的程式不是這樣。資料會從網路、檔案、使用者的輸入進來，而第 1 章說過：TypeScript 只能檢查它看得到的程式碼。從外面來的資料，它在檢查的時候根本看不到。這一章要處理的就是這條界線：

- `async` 函式和 `Promise.all` 的型別，以及忘了寫 `await` 時會發生什麼事。
- `JSON.parse` 和 `fetch` 給你的資料為什麼是 `any`，這為什麼危險。
- 把外部資料當成 `unknown`，用第 5 章學過的型別縮小和型別守衛，一步一步確認它長得對不對。
- `try...catch` 抓到的錯誤，型別是 `unknown`，要怎麼處理。

這一章會大量用到第 2 章的 `unknown`、第 5 章的型別縮小與型別守衛，以及第 6 章的 `Promise<T>`。如果印象有點模糊，可以先回去翻一下。

範例一樣在 `ts-practice` 資料夾裡練習。為了讓範例不依賴網路、每次執行結果都一樣，需要伺服器回應的地方，都用 `new Response(...)` 假裝收到了回應，第 6 集會說明這個做法。
