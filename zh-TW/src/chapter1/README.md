# TypeScript 第一步

你已經會寫 JavaScript 了。這一章要做的事很少，但每一件都會用到全書：

- 搞懂 TypeScript 解決了什麼問題。
- 建立 `ts-practice` 練習資料夾，第 1～10 章都在這裡練習。
- 學會兩個指令：用 `node` 執行 `.ts` 檔，用 `npx tsc` 檢查型別。
- 看懂 TypeScript 的錯誤訊息。這是整本書最常用到的技能。
- 認識兩個最基本的觀念：型別標註和型別推論。

這一章只會用到 `string`、`number`、`boolean` 三種型別，其他的型別從第 2 章開始教。

開始之前，請確認電腦上已經裝好 Node.js 24 以上的版本和 VS Code。如果還沒裝，可以照[《從零開始學 React》第 1 章第 2 集](https://holmeslin.github.io/learning-react-from-zero/zh-TW/chapter1/02_install_tools.html)的步驟安裝。
