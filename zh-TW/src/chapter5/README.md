# 聯集與型別縮小

到目前為止，每個變數、每個參數都只有一種型別：不是字串，就是數字。但真實的資料常常不是這樣：

- 商品編號可能是數字 `101`，也可能是字串 `"A01"`。
- 使用者的暱稱可能有填，也可能是 `null`。
- 一筆訂單可能是「處理中」、「已出貨」或「已取消」，每種狀態帶的資料都不一樣。

這一章教你怎麼描述「這幾種之一」，也就是**聯集型別**；以及更重要的另一半：拿到一個「可能是好幾種」的值之後，怎麼用 `if`、`switch` 一步一步確認它到底是哪一種，讓 TypeScript 跟著你的判斷**縮小**型別。

這一章學的寫法，幾乎每個 TypeScript 專案都會用到。尤其是第 7 集的「可辨識聯集」，是用型別描述資料最好用的工具之一。

這一章會用到第 2 章的型別別名（`type`）和第 3 章的物件型別。範例一樣在 `ts-practice` 資料夾裡練習。
