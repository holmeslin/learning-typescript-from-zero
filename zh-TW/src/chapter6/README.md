# 泛型

到目前為止，你寫的每個函式，參數都是固定的型別：`number` 就是 `number`，`string` 就是 `string`。但有很多函式根本不在乎收到的是什麼型別，例如「拿出陣列的第一個元素」，數字陣列、字串陣列、物件陣列都一樣做。

這種函式如果用 `any` 寫，型別資訊就丟了；如果每種型別各寫一份，又太重複。**泛型**（generics）就是解決這個問題的工具：讓函式和型別多收一種參數，參數的內容是「型別」。

你其實已經用過泛型了。第 2 章的 `Array<string>`、第 3 章的 `Record<string, number>`，角括號 `<>` 裡面放的就是型別參數。這一章會解釋它們到底是什麼，並教你自己寫：

- 為什麼需要泛型，以及泛型函式怎麼寫
- TypeScript 怎麼自己推論出型別參數
- 泛型型別與泛型介面
- 用 `extends` 限制型別參數能放什麼
- 預設型別參數
- 內建的泛型：`Array`、`Map`、`Set`、`Promise`

泛型是 TypeScript 裡看起來最嚇人的語法，但核心觀念只有一個：**型別也可以當參數傳**。抓住這一點，其他都只是變化。
