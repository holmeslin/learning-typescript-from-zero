# 專案設定與模組

從這一章開始是第二部：把 TypeScript 用在真實的專案。

第一部的範例都是一個檔案就能跑完的小程式，`tsconfig.json` 也是照抄就好。但真實的專案會有很多檔案互相 `import`，會用到別人寫的套件，有些套件還是用 JavaScript 寫的、沒有附型別。這一章處理的就是這些「程式碼以外」的事：

- 把第 1 章照抄的 `tsconfig.json` 逐項看懂，知道 `strict` 到底打開了什麼。
- 認識兩個更嚴格的選項，它們能抓到第 3、6 章提過、預設抓不到的錯誤。
- 在多個檔案之間匯出、匯入型別，以及 `import type` 和副檔名的規則。
- 看懂 `.d.ts` 宣告檔，知道 `@types` 套件是什麼。
- 遇到沒有型別的套件時，自己替它寫宣告。

這一章有不少範例需要好幾個檔案，或是要暫時修改 `tsconfig.json`。每一集都會寫清楚要建立哪些檔案、改了什麼，以及看完之後要怎麼改回來。範例一樣在 `ts-practice` 資料夾裡練習。
