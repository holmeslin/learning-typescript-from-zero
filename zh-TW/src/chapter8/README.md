# 型別運算

到目前為止，你寫的型別都是「一個字一個字寫出來」的：物件有哪些屬性、每個屬性是什麼型別，全部自己列。但實際寫程式時，很多型別其實已經藏在別的地方了：

- 設定檔的物件已經寫好了，型別能不能直接從它拿？
- 有了 `User` 型別，「所有屬性都可以不填的 `User`」、「拿掉密碼的 `User`」，能不能不要重寫一遍？
- 函式已經寫好了，它的回傳值型別能不能直接拿來用？

這一章教你**從現有的東西產生新的型別**，就像用函式從舊的值算出新的值一樣：

- 用 `typeof`、`keyof`、索引存取，從值和型別裡取出型別。
- 用 `as const` 取代其他語言的 `enum`，用 `satisfies` 檢查型別又不失去細節。
- TypeScript 內建的工具型別，例如 `Partial`、`Pick`、`Omit`、`Record`、`ReturnType`。
- 映射型別、條件型別、`infer`、樣板字面值型別。這四個是「入門就好」：你會在函式庫的型別裡常常看到，看得懂就夠了，不要求會自己寫。

這一章會用到第 3 章的物件型別、第 5 章的聯集與字面值型別，以及第 6 章的泛型。範例一樣在 `ts-practice` 資料夾裡練習。
